### FPGA & Computer Architecture

**[RetroFPGA Computer Museum](https://github.com/retrofpga-computer-museum)**  
An educational initiative to reconstruct and study historical computer architectures through programmable logic. Work includes the Basys 3 FPGA learning path, video output, menu/controller logic, testbenches, and processor architecture experiments.

The museum's broader roadmap includes historical and educational architectures such as SAP-1, Hack, MOS 6502, Z80, Motorola 68000, and DCPU-16. **Roadmap entries are not claims that every core is complete or hardware-verified.**
